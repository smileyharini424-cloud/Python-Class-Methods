# Python Class Methods

## Explanation

Methods are functions defined inside a class. Python supports different types of methods, including instance methods, class methods, and static methods.

This program demonstrates all three types using a `Student` class.

## Problem Statement

Write a Python program to demonstrate instance methods, class methods, and static methods using a class.

## Features

* Demonstrates instance methods
* Demonstrates class methods
* Demonstrates static methods
* Uses `self`
* Uses `cls`
* Uses `@classmethod`
* Uses `@staticmethod`

## How It Works

1. The `Student` class is created.
2. An instance method displays individual student information.
3. A class method displays information shared by the class.
4. A static method performs a general operation that does not depend on object or class data.
5. All three methods are called separately.

## Technologies Used

* Python 3
* Object-Oriented Programming
* Classes
* Instance Methods
* Class Methods
* Static Methods

## Program Flow

Start → Define Class → Create Object → Call Instance Method → Call Class Method → Call Static Method → Display Results → End

## Key Learning

* Instance methods use `self` and work with object data.
* Class methods use `cls` and work with class-level data.
* Static methods do not require `self` or `cls`.
* `@classmethod` creates a class method.
* `@staticmethod` creates a static method.
